# Afsha Fathima — Portfolio

Personal portfolio of Afsha Fathima, a Python Backend Developer.

**Live site:** https://afshafathima.com

## About

A terminal-themed, monochrome neo-brutalist portfolio built with plain HTML, CSS and JavaScript. All content is loaded from JSON files in `data/`, so updating the site means editing data, not code.

## Structure

- `index.html` — page shell
- `assets/css/style.css` — styles
- `assets/js/main.js` — renders each section from `data/*.json`
- `assets/img/` — profile photo, company logos, project images
- `data/` — hero, about, experience, skills, projects, education, contact
- `CNAME` — custom domain for GitHub Pages

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
